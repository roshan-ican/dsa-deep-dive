# MAANG-style DSA practice roadmap

These files contain questions only. They intentionally contain no solutions, pseudocode, or algorithm hints.

Work through the topics in this order:

1. `array`
2. `hash`
3. `sorting`
4. `two_pointer`
5. `sliding_window`
6. `stack_queue`
7. `search`
8. `linkedList`
9. `doublyLinkedList`
10. `recursion`
11. `trees`
12. `heaps`
13. `backtracking`
14. `tries`
15. `graphs`
16. `graphTraversal`
17. `union`
18. `greedy`
19. `intervals`
20. `dynamicProgramming`
21. `dynamicProgramming2D`
22. `bit_manipulation`
23. `math_geometry`

For each question:

1. Create a separate solution file yourself.
2. Write down the input, expected output, and brute-force idea before coding.
3. Test your own solution locally.
4. Ask for a review only after making an attempt.
